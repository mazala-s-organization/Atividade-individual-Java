# Atividade-individual-Java

📌 Sur Le Fond (Continuação individual)

Este projeto tem como objetivo desenvolver um sistema simples e funcional para um site de cosméticos. A solução foi criada no FlutterFlow, onde foram planejadas as telas de Login, Cadastro, Tela inicial, Endereço e Dados do Usuário, todas com navegação completa e integração com a API.

-----------------------------------------------------------------------------------------------------------
✨ Funcionalidades das telas

--> Página "cadastro" possui um formulário para criar uma nova conta, coleta informações básicas do usuário (nome, e-mail, senha) e armazena os dados do usuário no sistema.

--> Página "login" permite que o usuário acesse sua conta de forma segura. Redireciona para a tela inicial após o login.

--> Página "home/inicial" fala um pouco sobre a marca, explicando missão, visão e ideias. Inclui elementos, como: Header com navegação, logo da marca, texto de apresentação, ícones representando seções e funções e botão de acesso rápido para outras telas.

--> Página "dados do usuário" mostra e permite editar informações pessoais do usuário.

--> Página "cadastro do endereço" é um formulário completo para cadastro ou edição de endereço, possuindo logradouro, localidade, cep, número, complemento, bairro e 
referência.

--------------------------------------------------------------------------------------------------------
🛠️ Tecnologias Utilizadas

FlutterFlow – Construção das telas do aplicativo.

VS Code – Construção do código backend.

GitHub – Guarda o histórico completo do desenvolvimento do código, dentro do repositório.

Render – Deploy/hospedagem das funcionalidades do backend.
